# ZimCrafts Mobile

Expo React Native app for ZimCrafts Hub.

## Setup

1. Copy `.env.example` to `.env`.
2. Set `EXPO_PUBLIC_API_BASE_URL` to your backend URL, for example `https://zimcrafts-hub.onrender.com/api/v1`.
3. Install dependencies with `npm install`.
4. Start the app with `npx expo start`.

## Features

- JWT auth stored with `expo-secure-store`
- Customer product browsing and manual checkout
- Tutorials and enrollment requests
- Artisan dashboard, orders, wallet, and tutorial request handling
- Brown craft-themed UI with React Native Paper
